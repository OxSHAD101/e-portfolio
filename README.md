# Shahariar Shad aka 0xShad — Portfolio

A responsive, static cybersecurity portfolio designed for GitHub Pages.

## Files
- `index.html` — page content
- `style.css` — visual design and responsive layout
- `script.js` — searchable 71-program directory and interactions
- `company.png` — your company-logo showcase image (add this)
- `reward.png` — your disclosed/rewarded research artwork (add this)

## Add your images
Copy the two image files you saved into this project folder, beside `index.html`:
- `D:\portfolio\company.png` → project root as `company.png`
- `D:\portfolio\reward.png` → project root as `reward.png`

If Windows hides extensions, make sure the actual filenames are `company.png` and `reward.png` (not `company.png.png`).

## Deploy to a fresh GitHub Pages repository
1. Create a repository named `oxshad101.github.io` under the GitHub account `oxshad101` (or use your chosen repository name).
2. Upload all files in this folder, including both image files.
3. In GitHub, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Your site should be available at `https://oxshad101.github.io/`.

## Edit content
- Update program names in the `programs` array in `script.js`.
- Change email or links in the Get in Touch section in `index.html`.
- The directory deliberately displays program names only, as requested.

## Privacy reminder
Some supplied invitations were marked private in the source information. Confirm you are permitted to disclose every program name before publishing the full directory publicly. The portfolio does not show invitation status, scope, report counts, or reward ranges.
